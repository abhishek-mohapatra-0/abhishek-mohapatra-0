## 🚀 Featured projects

### 🛰️ [SLA Monitoring Agent](https://github.com/abhishek-mohapatra-0/sla-monitoring-agent)

[![SLA Monitoring Agent](https://raw.githubusercontent.com/abhishek-mohapatra-0/sla-monitoring-agent/main/docs/images/banner.png)](https://github.com/abhishek-mohapatra-0/sla-monitoring-agent)

An AI agent that monitors IT service-desk SLAs on 61,884 tickets:

- **Root cause:** an automatic drill-down that explains *why* SLAs breach.
- **Breach prediction:** a gradient-boosting model flags open tickets likely to breach (**ROC AUC 0.78** on a time-based holdout).
- **Daily report:** written and e-mailed every morning.
- **Q&A in plain English:** an LLM with tool calling (Groq / Gemini / Ollama) answers questions.
- **Dashboards:** comes with a 5-page **Power BI** report and a **Flask** web dashboard.
- **Tests:** 18 automated tests.

`Python` `pandas` `scikit-learn` `Flask` `Power BI` `DAX` `LLM tool calling`

### 🧠 [Text-to-SQL Agent](https://github.com/abhishek-mohapatra-0/text-to-sql-agent)

Ask a database questions in plain English. **Gemini** writes the SQL, runs it on **MySQL** and returns paginated results. Enterprise features:

- **Guardrails** that block destructive queries (DROP / DELETE / UPDATE)
- a live schema browser
- token and cost telemetry per session
- database storage metrics

`Python` `Streamlit` `Gemini` `MySQL` `SQLAlchemy`
